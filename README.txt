JARVIS - voice assistant for Android
1. Install Android Studio (free) -> File > Open -> select this "Jarvis" folder. Wait for Gradle sync.
2. Build > Build Bundle(s) / APK(s) > Build APK(s). Click "locate" -> app-debug.apk
3. Copy the APK to your phone and install it (allow "install unknown apps").
4. Open Jarvis, tap buttons 1, 2, 3 then START JARVIS. Say "Jarvis, open YouTube".
Tip: On Samsung/Xiaomi/Oppo etc. set Jarvis battery to "Unrestricted" so it isn't killed in the background.

ONE-CLICK DOWNLOAD (no Android Studio):
Upload this folder to a GitHub repo. The build runs automatically and publishes Jarvis.apk to Releases.
Permanent link:  https://github.com/YOUR_USERNAME/YOUR_REPO/releases/latest/download/Jarvis.apk
Or open Download-Jarvis.html, type "username/repo" and tap the button.
